\section{Discussion}

\paragraph{What new property was demonstrated?}
% claims: C01 C05 C13; sources: S01 S02 S05 S06 S13
In one selected engineered model, a trusted receipt for a causally operative
state class can gate a state-specific statistical regularity inside constrained
generated text. The intervention study grounds the state in the learned
computation; receipts authenticate the event, class, and registered chain; and
the carrier places compatibility with the derived class inside the output.
These layers remain distinct. The output score does not authenticate the exact
execution or receipt chain by itself.

\paragraph{Why not use only a receipt or a watermark?}
% claims: C01 C05 C13; sources: S01 S02
A sidecar or inline MAC is simpler and cryptographically stronger for declared
metadata, but its evidence remains external to the artifact. A conventional
watermark places a keyed signal inside text, but its key need not correspond to
a causally relevant state of the producing computation. Their composition
provides the narrower conjunction evaluated here: authenticated evidence
grounds a state class, and that class selects the regularity carried in the
output. We did not measure whether this added property is operationally useful
or preferable to a sidecar.

\paragraph{Strongest alternative interpretation.}
% claims: C01 C03; sources: S03 S04
Trusted middleware reads a trusted state label and encodes that label into
text. This is a valid description of the construction. The causal experiment
adds evidence that, for selected Model 1, the label denotes a registered state
that changes the learned downstream mapping rather than an arbitrary
annotation detached from the model. It does not show that the surface generator
directly consumes a neural activation, or that causal grounding adds value over
a controller supplied with the same trusted label. A future label-direct
baseline would need to test that comparison explicitly.

\paragraph{Why the protected failure matters.}
% claims: C08 C10 C11; sources: S10 S14 S15 S16 S17
The perfect public result is insufficient for a robustness claim. Protected
qualification failed a frozen, non-compensatory computation gate at one
closure; its descriptive 127/128 cannot be reinterpreted as a protected
success. Because qualification was not earned, final protected confirmation
was not run. This boundary prevents claims of protected generalisation even
though the public integration passed every closure.

\paragraph{Trusted assumptions and scientific scope.}
% claims: C01 C02 C10 C12; sources: S03 S04 S14 S15 S18
The checkpoint, state-boundary instrumentation, receipt issuer, controller,
verifier, and key custody are trusted. The model is tiny; its states are
supervised, categorical, and mandatory; and its text is templated. One
checkpoint, grammar, bias, length, and authority family are tested. The work
provides no evidence for naturally emerging or distributed states, open-ended
language, human imperceptibility, semantic robustness, paraphrase or copy
resistance, adaptive attacks, malicious issuers, compromised keys, deception
detection, frontier-model applicability, or whole-reasoning provenance.
Sixteen fixed authorities do not establish robust four-bit capacity. The
two-of-three seed outcome further limits the result to the prospectively
selected model.

\paragraph{Toward realistic scalable oversight.}
% claims: C01 C13
A realistic extension would need to identify causally meaningful states in
non-toy models without supervising them into existence; test transport across
tasks, checkpoints, and seeds; reduce trust in instrumentation and the
controller; compare directly against label-only and sidecar baselines; and
evaluate open-ended generation under editing, paraphrase, copying, translation,
adaptive attacks, and key compromise. It would also need experimental units
that capture deployment variation rather than repeated outputs from a shared
template family.

\paragraph{Ethics and reproducibility.}
% claims: C08 C11; sources: S10 S16 S17
State-conditioned output carriage could support audit trails, but it could also
enable covert labelling, surveillance, or false confidence in machine-generated
evidence. Deployment would require consent, transparent key governance,
redress, and explicit communication that statistical scoring is not output-only
authentication. Claim-bearing results here are bound to frozen configurations
and retained rows. Independent reconstruction checks the recorded
evidence-to-verdict chain; it is not an independent neural execution or
experimental replication.
