# External review intake checklist

Complete this checklist when a report is returned. Do not mark a report as
independent merely because it is favourable.

## Provenance

- [ ] Reviewer identity or stable anonymised code recorded.
- [ ] Review date recorded.
- [ ] Prior involvement and conflicts disclosed.
- [ ] Evidence commit is exactly `15e25785eee560cf0242ff781dedb4ea4fc0e809`.
- [ ] Review-manifest digest is exactly
      `06777ebe219da0286be83359565b6179987954c42f2c04f64cd9a8db6dce3bbf`.
- [ ] Commands and environment recorded.
- [ ] Report SHA-256 or signature recorded.

## Substance

- [ ] Causal operation of `z2` assessed.
- [ ] Fixed prompt, answer, payload, and primitive draws assessed.
- [ ] Verification-before-authority ordering assessed.
- [ ] Exact and abstract provenance distinction assessed.
- [ ] Prospective thresholds and denominators assessed.
- [ ] Public 128/128 and protected 127/128 evaluated separately.
- [ ] Selected-model, engineered-bottleneck, trusted-receipt, and engineered
      realiser assumptions assessed.
- [ ] “SynthID-style” terminology assessed.
- [ ] Sidecar-HMAC comparison assessed.
- [ ] Unresolved concerns listed.
