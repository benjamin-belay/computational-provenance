# Request for independent methodological review

We invite an independent methodological review of a bounded computational
provenance proof of concept.

## Requested assessment

Please answer two questions separately:

1. Does the archived public evidence support a bounded demonstration that a
   statistical output signal tracks an authenticated, causally operative
   abstract state while prompt, answer, semantic payload, and primitive random
   draws remain fixed?
2. Does the evidence establish protected or broader generalisation?

The project currently reports the first as prospectively validated on 128/128
public closures and the second as not established. Protected qualification
produced a descriptive 127/128 but did not pass.

## Desired reviewer background

The reviewer should:

- disclose prior involvement or conflicts;
- preferably have no role in implementation or gate selection;
- understand ML experimentation, statistical validation, security evidence,
  or closely related methodology;
- be willing to record critical and major findings.

## Requested report

Return a Markdown or PDF report containing:

- reviewer identity or stable anonymised code;
- date, environment, commit, and manifest digest;
- commands executed and reconstruction results;
- critical, major, minor, and accepted findings;
- unresolved concerns;
- separate assessments of the public and protected claims;
- SHA-256 or optional signature of the completed report.

The report will receive a point-by-point response. Historical evidence will
not be changed in response.
