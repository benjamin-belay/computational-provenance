# RNG2 receipt-bound integration: archival handoff

Status: `MAIN_CSW_AM_SCB_M1_RNG2_INT_FINAL_PROGRAMME_CONSOLIDATED`

This directory is the publication, reproducibility, and archival handoff for
the closed `CSW-AM-SCB-M1-RNG2-INT` programme. It adds no scientific evidence,
authorizes no successor, and exposes no protected confirmation identity.

This GitHub edition is intentionally curated. It retains the paper-facing
record, compact claim-bearing audits, integrity verifier, review package, and
environment lock files. Raw development traces, checkpoints, rehearsals,
sealed identities, private key material, and superseded attempts are not
published. See [CURATION.md](CURATION.md).

## Headline result

> A prospectively validated proof of concept in which generated output
> statistically identifies an authenticated causal state, even when prompt,
> answer, semantic payload, and paired randomness are unchanged.

The result was obtained in one selected model with an explicitly supervised
mandatory hard bottleneck, trusted HMAC receipt infrastructure, and an
engineered position-indexed stochastic realiser.

The public integration validation passed 128/128 complete closures. The
protected qualification did **not** pass: it produced a descriptive 127/128,
including one computation-fidelity failure and two dependent attack failures.
Final protected confirmation was not run.

## Non-experimental boundary

The handoff must not be used to:

- rerun or repair protected qualification;
- release the 256 sealed confirmation closures;
- replace the failed protected closure;
- pool public validation with protected qualification;
- relabel the frozen Q1 terminal;
- imply production SynthID equivalence;
- claim provenance for unconstrained distributed reasoning.
