# Curated GitHub publication boundary

This directory publishes the smallest useful, reviewable record of the closed
`CSW-AM-SCB-M1-RNG2-INT` programme.

## Included

- the programme result, claims matrix, limitations, and chronology;
- the paper draft, appendices, source-data tables, generated SVG figures, and
  figure generator;
- external-review instructions, reporting policy, and verification script;
- 13 compact claim-bearing audit and closure records referenced by
  `PUBLIC_ARTIFACT_MANIFEST.json`;
- a standard-library-only Level-1 integrity verifier;
- dependency specification snapshots from the source research repository;
- the sealed-population attestation without protected identities.

## Excluded

- model checkpoints and tensor arrays;
- raw JSONL execution traces and training predictions;
- virtual environments, caches, and generated bytecode;
- private keys, unrevealed authorities, protected identities, and controller
  workspaces;
- development rehearsals, failed launch scaffolding, and superseded attempts;
- duplicated historical packages and local archival clones.

The exclusions reduce repository size and avoid publishing sensitive or
non-claim-bearing material. They also mean this GitHub edition supports the
self-contained Level-1 integrity check but not raw-row reconstruction or full
model regeneration. Those stronger replay paths require the separately
retained archival research workspace.

The external-review verifier is preserved byte-for-byte as part of the review
release. It binds to an archival source commit that is not included in this
curated repository, so executing that verifier also requires the archival Git
object database. The Level-1 handoff verifier does not have that dependency.
